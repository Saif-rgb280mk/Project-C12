# KINETIC XI

An original, physics-first football (soccer) simulation design plus working code. The project has four parts:

- **The mega-prompt and master design document:** `docs/KINETIC_XI_Master_Design_Prompt.md`.
- **A tested C++17 engine core:** ball aerodynamics, the living pitch, player inertia, foot IK, fatigue, the MacBook keyboard arbiter, settings, tactical AI and camera.
- **A macOS layer:** Objective-C++ keyboard capture, a Swift Apple Silicon governor and a Metal grass shader.
- **A playable browser prototype** that uses the exact MacBook key layout.

**Everything in one PDF:** `dist/KINETIC_XI_Master_Blueprint_and_Source.pdf` (152 pages: design document, screenshots, every source file, test results, and a "what I used" study guide).

## Play it on your MacBook (no install)

1. Open `prototype/index.html` in Safari or Chrome.
2. Click the page, then press any key to kick off. **Esc** opens all the settings.
3. Important: macOS uses **Control + Arrow keys** for Mission Control. To free them, go to System Settings → Keyboard → Keyboard Shortcuts… → Mission Control, and untick "Mission Control", "Application windows", "Move left a space" and "Move right a space". Alternatively, rebind Sprint to Left Option in Esc → Controls.

| Action | Keys |
|---|---|
| Move · Sprint · Controlled sprint | Arrows · Left Ctrl + Arrows · D (off the ball) or feathered Ctrl |
| Ground pass / Lob · Cross | S tap / S hold |
| Through · Lobbed through | A · Left Shift + A |
| Shoot · Finesse · Driven pass | D · D + E (in range) · D + E (elsewhere) |
| Shield · Strafe · Stop ball · Skills | W · Left Shift · Left Ctrl tap · E + arrow gestures |
| Defending | Shift change · W jockey · E contain · D teammate contain · S slide · W/E + D tackle · A rush GK |

## Build and test the engine

```bash
cmake -S engine -B build -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build
```

```bash
./build/kxi_tests
```

```bash
./build/kxi_lab
```

`kxi_tests` runs 45 tests (271 checks); `kxi_lab` prints the physics lab tables.

## Rebuild the PDF

```bash
pip3 install reportlab pygments pillow
```

```bash
python3 tools/build_pdf.py
```

## Layout

| Folder | Contents |
|---|---|
| `engine/` | C++17 engine core, tests, physics lab, CMake |
| `platform/macos/` | Objective-C++, Swift, Metal |
| `prototype/` | HTML/CSS/JavaScript playable prototype |
| `config/` | JSON defaults generated by the engine |
| `docs/` | design document sources, results, screenshots |
| `tools/` | browser tests (Playwright) and PDF builder (Python) |
| `dist/` | the finished PDF |
